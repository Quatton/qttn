JavaScript での実装はかなり遅かったので、リアルタイムで結果を表示するには困難ということが判明した。工夫として、WebGL を使って、GPU で計算することを試みた。これにより、リアルタイムでのフィルタリングが可能になった。

状態の管理は、`nanostores` というライブラリを使用している。これは、Postcss やその他のパッケージサイズを配慮した軽量なライブラリ群の一部で、[Andrey Sitnik](https://github.com/ai) によって開発されている。彼も CRDT やリアルタイム通信関連のライブラリを開発しており、非常に信頼性が高い。

それはさておき、まずは​サンプルコードをそのまま使って、

```javascript

function smoothImageBilateral(
  imgData: ImageData,
  sigma: number,
  sigmaColor: number,
) {
  const data = imgData.data;

  const r = Math.ceil(sigma * 3);

  const r2 = 2 * r + 1;
  const stencil = new Float32Array(r2 * r2);

  for (let dy = -r; dy <= r; dy++) {
    for (let dx = -r; dx <= r; dx++) {
      const h = Math.sqrt(dx * dx + dy * dy);
      const idx = (dy + r) * r2 + (dx + r);
      stencil[idx] = Math.exp(-(h * h) / (2 * sigma * sigma));
    }
  }

  for (let px = 0; px < imgData.width; px++) {
    for (let py = 0; py < imgData.height; py++) {
      let rSum = 0,
        gSum = 0,
        bSum = 0,
        weightSum = 0;

      const idx = (py * imgData.width + px) * 4;
      const r0 = data[idx];
      const g0 = data[idx + 1];
      const b0 = data[idx + 2];

      for (let dy = -r; dy <= r; dy++) {
        for (let dx = -r; dx <= r; dx++) {
          const px1 = px + dx;
          const py1 = py + dy;
          if (
            px1 < 0 ||
            px1 >= imgData.width ||
            py1 < 0 ||
            py1 >= imgData.height
          ) {
            continue;
          }
          const idx1 = (py1 * imgData.width + px1) * 4;
          const weightSpace = stencil[(dy + r) * (2 * r + 1) + (dx + r)];
          // TODO: take distance between pixel colors at idx0 & idx1, plug it into Gaussian
          const r1 = data[idx1];
          const g1 = data[idx1 + 1];
          const b1 = data[idx1 + 2];
          let weightColor = Math.exp(
            -(
              (r1 - r0) * (r1 - r0) +
              (g1 - g0) * (g1 - g0) +
              (b1 - b0) * (b1 - b0)
            ) /
              (2 * sigmaColor * sigmaColor),
          );

          const w = weightSpace * weightColor;
          rSum += r1 * w;
          gSum += g1 * w;
          bSum += b1 * w;
          weightSum += w;
        }
      }

      data[idx] = Math.round(rSum / weightSum);
      data[idx + 1] = Math.round(gSum / weightSum);
      data[idx + 2] = Math.round(bSum / weightSum);
      data[idx + 3] = 255;
    }
  }

  return imgData;
}
```

それを `WebGL` 化して、GPU で計算することにした。

```glsl
vec4 smoothImageBilateral(vec4 color, float sigma, float sigmaColor) {
  int r = int(ceil(sigma * 3.0));
  vec2 texelSize = 1.0 / vec2(textureSize(u_image, 0));
  vec3 result = vec3(0.0);
  float weightSum = 0.0;
  vec4 centerColor = texture(u_image, v_texCoord);

  for (int dy = -r; dy <= r; dy++) {
    for (int dx = -r; dx <= r; dx++) {
      vec2 offset = vec2(float(dx), float(dy)) * texelSize;
      vec2 sampleCoord = v_texCoord + offset;

      if (sampleCoord.x < 0.0 || sampleCoord.x > 1.0 ||
          sampleCoord.y < 0.0 || sampleCoord.y > 1.0) {
        continue;
      }

      vec4 sampleColor = texture(u_image, sampleCoord);
      float h = sqrt(float(dx * dx + dy * dy));
      float weightSpace = exp(-(h * h) / (2.0 * sigma * sigma));

      float colorDistance = length(sampleColor.rgb - centerColor.rgb);
      float weightColor = exp(-(colorDistance * colorDistance) / (2.0 * sigmaColor * sigmaColor));

      float weight = weightSpace * weightColor;

      result += sampleColor.rgb * weight;
      weightSum += weight;
    }
  }

  return vec4(result / weightSum, color.a);
}`;
```

だだし、`WebGL` はやはり `vec36` がさすがに使えないので、仕方なく `O(n * 2)` のアルゴリズムを使うことにした。そのため、stencil を作る意味がなくなり、直接ループ内で計算することになった。

`offset` の計算はピクセルではなく、テクセル単位で行う必要がある。テクセルはテクスチャーマッピングの座標で、0.0 から 1.0 の範囲で表現される。そのため、事前に `1.0 / textureSize(u_image, 0)` を計算しておいた。この公式ドキュメンテーションは非常に役に立った。[MDN Web Docs: Using textures in WebGL](https://developer.mozilla.org/en-US/docs/Web/API/WebGL_API/Tutorial/Using_textures_in_WebGL)

そして、`detail` と `enhance` の部分は２つ以上のテクスチャーを使用する必要があって、これは​ [WebGL Fundamentals: WebGL Using 2 or More Textures](https://webglfundamentals.org/webgl/lessons/webgl-2-textures.html) を参考にした。

元の課題例はハードコードで `+ 128` していたが、工夫 (? というより実験) として、`detailOffset` も指定できるようにした。範囲は `0.0` から `1.0` までである。
(128 についていえば、WebGL の色は `0.0` から `1.0` の範囲で表現されるため、`128` は `0.5` に相当する。 そのため、`sigmaRange` も 0.01 から 2.0 までの範囲で指定できるようにした。)
